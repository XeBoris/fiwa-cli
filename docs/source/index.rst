Welcome to FiWa CLI Documentation
==================================

FiWa CLI is a terminal-based financial tracking application built with Textual.

Features
--------

* **Interactive Calendar**: Navigate and select dates with ease
* **Expense Tracking**: Record and manage financial transactions
* **Data Visualization**: View expenses in calendar and list formats
* **File Logging**: Comprehensive logging with rotation support
* **Textual UI**: Modern terminal user interface
